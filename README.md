## 🚀 Live Preview / Local Setup

Because this site is built purely with standard HTML5, CSS3, and vanilla JavaScript without any external build tooling, you can preview it immediately:

### Option 1: Open Directly
Double-click `index.html` or open it with any web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Live Server / Python HTTP
From this directory (`saads-portfolio/personal-website/`), run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

### Option 3: Instant GitHub Pages Deployment
1. Push this folder to a GitHub repository (e.g. `saadkarim754.github.io`).
2. Go to **Settings** > **Pages** > Select branch `main` and root folder `/`.
3. Your site goes live instantly with SSL.
